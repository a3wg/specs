## Names and marks

"Accountable Agent Action", "A3" and "A3 Working Group" are the names of these specifications and of the group that maintains them. Nobody owns them as marks: no participant claims rights in them, or will register them, in a way that would restrict anyone implementing, describing or testing against the specifications. That includes Hubizens LLC, which builds the Rashnu runtime. The domains `a3wg.org` and `a3wg.com` are held for the Working Group by its maintainers, not by any company, and will move with the specifications to a neutral home. Anyone may say that an implementation conforms to an A3 specification when it does, and may name what it conforms to.

Rashnu, the reference implementation of these specifications, is built by Hubizens LLC. The name refers to that implementation, not to the specifications.
